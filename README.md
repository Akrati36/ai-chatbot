# AI Chatbot

A complete AI chatbot built with React and OpenRouter API.

## Features

- 🤖 Real-time AI conversations
- 💬 Clean and modern UI
- 🔐 Secure API key storage
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Beautiful gradient design

## Setup

1. Clone the repository:
```bash
git clone https://github.com/Akrati36/ai-chatbot.git
cd ai-chatbot
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Get your free API key from [OpenRouter](https://openrouter.ai/keys)
5. Click the settings button (⚙️) in the chat header
6. Enter your API key and save
7. Start chatting!

## Technologies Used

- React
- OpenRouter API (using free Llama 3.1 model)
- CSS3 with animations
- LocalStorage for API key persistence

## How It Works

The chatbot uses OpenRouter's API to access the Meta Llama 3.1 8B model (free tier). Your API key is stored locally in your browser for security.

## Customization

You can easily customize:
- AI model (change in `src/App.js`)
- Colors and styling (modify `src/App.css`)
- Chat behavior and system prompts

## Deployment

You can deploy this chatbot to:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting service
